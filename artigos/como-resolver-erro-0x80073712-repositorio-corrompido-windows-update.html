Como Resolver o Erro 0x80073712 de Repositório Corrompido no Windows Update

7 min de leitura Atualizado em agosto de 2026 Equipe DRGTech Nível: Prático
Resposta Rápida: O erro 0x80073712 (ERROR_SXS_COMPONENT_STORE_CORRUPT) ocorre quando os arquivos do manifesto de atualizações do Windows estão corrompidos. Para corrigir, abra o Prompt de Comando (Admin), rode 'dism /online /cleanup-image /startcomponentcleanup' e limpe a pasta C:\Windows\SoftwareDistribution.

Passo a Passo Completo

  1. 1
    Abra o Prompt de Comando como Administrador e execute 'dism /online /cleanup-image /startcomponentcleanup' para remover manifestos corrompidos.
  2. 2
    Pare os serviços de atualização digitando 'net stop wuauserv' e 'net stop bits'.
  3. 3
    Navegue até a pasta C:\Windows\SoftwareDistribution\Download, apague todos os arquivos temporários e reinicie os serviços com 'net start wuauserv'.
