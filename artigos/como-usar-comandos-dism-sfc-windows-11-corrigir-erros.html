Como Usar DISM e SFC no Windows 11 para Reparar Arquivos do Sistema

7 min de leitura Atualizado em novembro de 2026 Por Renato Braga
Resposta rápida: Para reparar o Windows 11, abra o Terminal como Administrador e execute primeiro o DISM para restaurar a integridade da imagem de componentes com DISM /Online /Cleanup-Image /RestoreHealth. Em seguida, execute o Verificador de Arquivos do Sistema com sfc /scannow. Essa ordem é obrigatória porque o SFC depende de uma base de componentes saudável na pasta WinSxS para substituir arquivos corrompidos.

O Verificador de Arquivos do Sistema (SFC) e o Gerenciamento e Manutenção de Imagens de Implantação (DISM) são as ferramentas nativas mais poderosas da Microsoft para diagnosticar e restaurar arquivos corrompidos no Windows 11. Quando o computador apresenta lentidão inexplicável, erros ao abrir o Explorador de Arquivos, travamentos na Barra de Tarefas ou mensagens genéricas de falha de biblioteca DLL, essas duas ferramentas permitem recuperar a estabilidade operacional sem a necessidade de formatar o disco rígido ou reinstalar aplicativos do zero.

No entanto, um dos erros mais comuns cometidos por usuários e técnicos iniciantes é executar apenas o comando SFC ou executá-los na ordem invertida. O utilitário SFC substitui versões corrompidas de arquivos do sistema a partir de um repositório compactado local armazenado na pasta WinSxS (Windows Side-by-Side). Se a própria imagem do repositório WinSxS estiver danificada por quedas de energia ou atualizações interrompidas, o SFC falhará e exibirá a mensagem de que não pôde corrigir os arquivos. Por essa razão, a documentação técnica da Microsoft estabelece como mandatório reparar previamente o repositório local com o DISM antes de rodar o SFC.

Aplica-se a: Windows 11 (todas as versões) e Windows 10

Entenda a Função Técnica de Cada Utilitário

Compreender o escopo de atuação de cada comando evita retrabalho e orienta o diagnóstico correto de falhas no sistema operacional Windows:

FerramentaEscopo de AçãoOrigem de ReparoTempo Médio
DISM (Deployment Image Servicing)Repara a imagem de recuperação do Windows e a integridade da pasta WinSxS.Servidores do Windows Update ou mídia de instalação oficial (ISO).10 a 25 minutos
SFC (System File Checker)Compara hashes de arquivos críticos do sistema ativo com a pasta WinSxS.Repositório local de componentes saudáveis verificado pelo DISM.5 a 15 minutos

Se a pasta WinSxS contiver inconsistências lógicas causadas por desligamentos abruptos ou falhas em atualizações cumulativas anteriores, o SFC não conseguirá obter versões íntegras para substituir arquivos corrompidos em C:\Windows\System32. O DISM resolve esse impasse baixando componentes limpos diretamente dos servidores oficiais da Microsoft.

Passo 1: Abrir o Terminal ou Prompt como Administrador

Os utilitários DISM e SFC interagem diretamente com diretórios protegidos do subsistema do Windows e exigem privilégios elevados de controle de conta de usuário (UAC) para modificar binários do kernel:

  1. 1
    Clique com o botão direito do mouse sobre o botão Iniciar do Windows 11 ou pressione o atalho de teclado Windows + X.
  2. 2
    No menu de contexto avançado, clique sobre a opção Terminal (Administrador) ou Prompt de Comando (Admin).
  3. 3
    Quando o Controle de Conta de Usuário (UAC) exibir a mensagem 'Deseja permitir que este aplicativo faça alterações no seu dispositivo?', selecione Sim.
  4. 4
    Verifique se o cabeçalho da janela do console exibe explicitamente o termo 'Administrador' antes de prosseguir com qualquer digitação de comando.

Certifique-se de que o computador esteja conectado à internet de forma estável durante a etapa do DISM. Caso você esteja em um ambiente corporativo com firewall restritivo ou sem acesso à rede externa, será necessário indicar uma imagem ISO oficial montada como fonte alternativa.

Passo 2: Diagnosticar e Reparar o Repositório com o DISM

O DISM possui três níveis progressivos de diagnóstico. Para uma manutenção preventiva e corretiva completa, recomenda-se executar a verificação avançada e em seguida o comando de restauração completa:

Primeiramente, execute uma varredura preventiva para averiguar se há danos registrados no repositório de componentes:

DISM /Online /Cleanup-Image /ScanHealth

Esse comando analisa todos os pacotes instalados sem realizar alterações ativas. Se o retorno indicar que 'O repositório de componentes é reparável', inicie a rotina de restauração executando a seguinte instrução:

DISM /Online /Cleanup-Image /RestoreHealth

Durante a execução do RestoreHealth, é perfeitamente normal que a barra de progresso pare aparentemente em 20%, 40% ou 62.3% por vários minutos seguidos. Não feche a janela do terminal nem reinicie o computador durante esse procedimento, pois o Windows está descompactando pacotes de integridade pesados em segundo plano.

Aguarde pacientemente até visualizar a mensagem de confirmação final: 'A operação de restauração foi concluída com êxito. A operação foi concluída com êxito.'

Passo 3: Executar a Varredura do SFC (System File Checker)

Com o repositório de componentes devidamente limpo e reparado pelo DISM, você pode rodar o Verificador de Arquivos do Sistema na mesma janela administrativa aberta:

sfc /scannow

O utilitário iniciará uma checagem de integridade detalhada em todas as pastas protegidas do sistema operacional. Ao final do processamento, você receberá um dos quatro diagnósticos documentados pela Microsoft:

  • 'A Proteção de Recursos do Windows não encontrou nenhuma violação de integridade': O sistema operacional está perfeitamente saudável e não há arquivos corrompidos.
  • 'A Proteção de Recursos do Windows encontrou arquivos corrompidos e os reparou com êxito': As falhas foram sanadas com sucesso utilizando a base de componentes que acabamos de validar com o DISM. Reinicie o computador para consolidar as alterações.
  • 'A Proteção de Recursos do Windows encontrou arquivos corrompidos, mas não pôde corrigir alguns deles': Indica falhas persistentes graves em bibliotecas em uso contínuo. Consulte a seção de inspeção de logs CBS abaixo.
  • 'A Proteção de Recursos do Windows não pôde executar a operação solicitada': Ocorre habitualmente quando o serviço do Instalador de Módulos está desativado ou ao rodar sem permissões de Administrador.

Passo 4: Como Inspecionar os Resultados no Arquivo CBS.log

O utilitário SFC armazena o histórico detalhado de todas as suas operações no arquivo de log do sistema localizado em C:\Windows\Logs\CBS\CBS.log. Como esse arquivo registra eventos de diversos outros componentes do Windows, você pode filtrar unicamente as entradas geradas pelo SFC gerando um relatório limpo na sua Área de Trabalho:

findstr /c:"[SR]" %windir%\Logs\CBS\CBS.log > "%userprofile%\Desktop\sfcdetails.txt"

Abra o arquivo sfcdetails.txt criado na sua Área de Trabalho com o Bloco de Notas para verificar os nomes exatos de arquivos DLL ou SYS que foram reparados pelo comando e identificar eventuais pendências.

Solução Alternativa: Executar o DISM Offline com Mídia de Instalação

Se o comando RestoreHealth falhar com o código de erro 0x800f081f ('Os arquivos de origem não puderam ser encontrados'), significa que o cliente do Windows Update local não conseguiu baixar os arquivos necessários da nuvem. A solução oficial consiste em montar uma imagem ISO oficial do Windows 11 e apontar o arquivo install.wim como fonte confiável de reparo:

  1. 1
    Baixe o arquivo ISO oficial do Windows 11 no site da Microsoft e dê um duplo clique para montá-lo no sistema (anote a letra da unidade virtual criada, como por exemplo E:).
  2. 2
    Abra o Prompt de Comando como Administrador e execute o comando abaixo, substituindo a letra E: pela letra correspondente à sua unidade montada:
  3. 3
    Certifique-se de que o arquivo de instalação se chama install.wim dentro da pasta sources da mídia montada.
DISM /Online /Cleanup-Image /RestoreHealth /Source:WIM:E:\sources\install.wim:1 /LimitAccess

O parâmetro /LimitAccess impede que o DISM tente recorrer aos servidores externos do Windows Update, forçando o uso estrito dos arquivos limpos contidos na mídia de instalação oficial.

Perguntas frequentes

Posso executar o SFC antes do DISM?

Você pode executar o SFC primeiro, mas se houver corrupção na base de componentes do Windows (pasta WinSxS), o SFC não conseguirá reparar os arquivos danificados e acusará falha irrecuperável. A boa prática recomendada pela documentação oficial da Microsoft é sempre executar o DISM com o parâmetro /RestoreHealth antes do sfc /scannow para assegurar que a fonte de substituição esteja íntegra.

O DISM ou o SFC podem apagar fotos, documentos ou programas pessoais?

Não. Tanto o DISM quanto o SFC atuam exclusivamente na pasta C:\Windows e nos arquivos binários do sistema operacional (como DLLs, executáveis do kernel, drivers nativos e arquivos de manifesto). Seus arquivos pessoais, pastas de usuário, fotos, documentos e programas instalados não sofrem nenhuma alteração ou exclusão.

O que fazer se o SFC travar em uma porcentagem específica durante a varredura?

Aguarde pelo menos 20 minutos. Se o processo realmente não avançar após esse período, reinicie o computador no Modo de Segurança com Prompt de Comando e execute o comando novamente. No Modo de Segurança, menos drivers e serviços de terceiros disputam o acesso aos arquivos protegidos do sistema.

Quantas vezes por mês devo rodar o DISM e o SFC no computador?

Essas ferramentas são utilitários de diagnóstico e reparo reativo, não de manutenção rotineira obrigatória. Não há necessidade de executá-las periodicamente se o sistema estiver estável. Utilize-as após quedas súbitas de energia, travamentos frequentes ou falhas ao instalar atualizações do Windows Update.

O que fazer se mesmo após o DISM e SFC o Windows 11 continuar apresentando erros?

Se as ferramentas concluírem sem erros mas a falha persistir, o problema pode estar em drivers corrompidos de terceiros, setores defeituosos no disco de armazenamento (execute chkdsk C: /f /r) ou falha física em pentes de memória RAM. Caso a causa seja do sistema operacional, uma instalação de reparo in-place (executar o assistente oficial do Windows mantendo aplicativos e arquivos pessoais) resolverá a questão sem formatação.
