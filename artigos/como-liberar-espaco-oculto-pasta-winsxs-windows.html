Como Liberar Espaço Oculto na Pasta WinSxS do Windows

Guia resumido, em revisão. Esta página é uma versão curta e ainda não passou pela nossa revisão editorial completa. As informações podem estar incompletas ou desatualizadas. Consulte a documentação oficial do fabricante antes de alterar configurações do sistema.

Resumo: A pasta WinSxS (Component Store) pode acumular dezenas de gigabytes em atualizações antigas e arquivos duplicados. Para liberar esse espaço com segurança sem corromper o sistema operacional, abra o Prompt de Comando (Admin) e execute o comando DISM para purga de componentes: dism /online /cleanup-image /analyzecomponentstore seguido por dism /online /cleanup-image /startcomponentcleanup /resetbase.

Passos resumidos

  1. 1
    Abra o Prompt de Comando como Administrador e execute 'dism /online /cleanup-image /analyzecomponentstore' para verificar quanto espaço a pasta WinSxS pode liberar.
  2. 2
    Rode o comando de limpeza profunda: 'dism /online /cleanup-image /startcomponentcleanup /resetbase' para consolidar os componentes do Windows.
  3. 3
    Execute o utilitário Limpeza de Disco (cleanmgr.exe) selecionando 'Limpar arquivos do sistema' para expurgar cópias de backup antigas.
