Como Corrigir o Erro 'DNS_PROBE_FINISHED_NXDOMAIN' no Navegador

7 min de leitura Atualizado em agosto de 2026 Equipe DRGTech Nível: Prático
Resposta Rápida: O erro DNS_PROBE_FINISHED_NXDOMAIN ocorre quando o servidor DNS não consegue traduzir o nome do domínio para um IP válido. Para resolver no Windows, abra o Prompt de Comando (Admin), execute 'ipconfig /flushdns', 'netsh winsock reset' e altere os servidores DNS da placa de rede para Cloudflare (1.1.1.1 e 1.0.0.1) ou Google (8.8.8.8).

Passo a Passo Completo

  1. 1
    Abra o Prompt de Comando como Administrador e execute os comandos: 'ipconfig /flushdns', 'ipconfig /release', 'ipconfig /renew' e 'netsh winsock reset'.
  2. 2
    Pressione Win + R, digite 'ncpa.cpl', clique com botão direito na sua conexão de rede e abra 'Propriedades'.
  3. 3
    Selecione 'Protocolo IP Versão 4 (TCP/IPv4)', marque 'Usar os seguintes endereços de servidor DNS' e insira 1.1.1.1 (DNS Preferencial) e 1.0.0.1 (DNS Alternativo).
